## Personal website

A responsive, static portfolio built with semantic HTML, CSS, and Vite. The book illustration is decorative CSS artwork, not a representation of published books.

### Run locally

Requires Node.js 20.19+ or 22.12+.

```sh
npm ci
npm run dev
```

### Production build

```sh
npm run build
npm run preview
```

The output is in `dist/`. It can be hosted by any static web host. No deployment is configured or triggered by this change.
